Career Quest 軽量化版

【差し替え方法】
1. このZIPを解凍します。
2. GitHubの career-quest リポジトリを開きます。
3. index.html / styles.css / script.js / assets フォルダ / .nojekyll を、既存ファイルと置き換えてアップロードします。
4. Commit changes を押します。
5. 数分後、現在と同じ公開URLで軽量化版が反映されます。

【主な変更】
・カード画像をスマホ表示向けWebPへ軽量化
・カード表示前に「カードを準備中」を表示
・カードをタップできることが分かる案内文へ変更
・うさぎの黒背景除去をブラウザ処理から透過済み画像へ変更
・見た目、カード内容、診断ロジックは維持
